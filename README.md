### Текст задачи

Первый массив, размерностью n х m, заполняется данными, вводимыми с клавиатуры, так что
заполнение ведется по столбцам от первых элементов столбца к последним.
Второй массив, размерностью n х n, заполняется так: элементы, лежащие выше побочной
диагонали, являются случайными числами из интервала [- 12;4565], а лежащие на побочной
диагонали и ниже, являются случайными числами из интервала [-1024; 1024].

1. Создан класс `MatrixTasks` с единственным полем `private int[,] _matrix`.
2. Для первого массива написан конструктор `MatrixTasks(int n, int m)`, в котором два цикла (внешний по столбцам, внутренний по строкам). Ввод проверяется через `Checked.ReadInt`.

# Задание 2. Работа с двумерными массивами

## Задача 2.3

### Текст задачи

Задан двумерный массив n х m. Найдите в нем подмассив 3 х 3, сумма элементов которого
максимальна. N и m могут быть не кратны трем.

### Алгоритм решения

1. В классе `MatrixTasks` создан метод `FindMax3x3Sum()`.
2. Метод использует алгоритм "скользящего окна". Два внешних цикла (`i` и `j`) определяют левый верхний угол окна 3х3.
3. Внутри окна два вложенных цикла (`r` и `c`) считают сумму 9 элементов.
4. Если текущая сумма больше максимальной, она запоминается.
5. В конце возвращается максимальная сумма.
