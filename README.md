# Задание 2. Работа с двумерными массивами

## Задача 2.3

### Текст задачи

Задан двумерный массив n х m. Найдите в нем подмассив 3 х 3, сумма элементов которого
максимальна. N и m могут быть не кратны трем.

### Алгоритм решения

1. В классе `MatrixTasks` создан метод `FindMax3x3Sum()`.
2. Метод использует алгоритм "скользящего окна". Два внешних цикла (`i` и `j`) определяют левый верхний угол окна 3х3.
3. Внутри окна два вложенных цикла (`r` и `c`) считают сумму 9 элементов.
4. Если текущая сумма больше максимальной, она запоминается.
5. В конце возвращается максимальная сумма.

### Тестирование

На скриншоте видно, что программа сгенерировала случайную матрицу размером 4х4 (размерность не кратна трем, как и указано в условии). 
Алгоритм "скользящего окна" успешно прошел по всем возможным положениям окна 3х3 и вычислил, что максимальная сумма элементов внутри такого подмассива равна 10112. Программа корректно обработала краевые условия матрицы.

# Задание 4. Бинарные файлы

## Задача 4.3

### Текст задачи

Получить в новом файле все компоненты исходного файла, которые делятся на m и не делятся на n.

### Алгоритм решения

1. В классе `FileTasks` написан метод `FillBinaryFile()`, который заполняет бинарный файл случайными числами (от -10 до 10).
2. Написан метод `Task4_3()`, который читает числа через `BinaryReader`.
3. Каждое число проверяется на условие `val % m == 0 && val % n != 0`. Если подходит — записывается в новый файл через `BinaryWriter`.
4. Значения `m` и `n` вводятся с клавиатуры с проверкой через `Checked.ReadInt`.

### Тестирование

На скриншоте продемонстрирована работа программы с бинарным файлом.

2. Затем пользователь вводит с клавиатуры значения `m = -7` и `n = 2`. (Значения вводятся через метод `Checked.ReadInt`, который проверяет корректность ввода).
3. Программа фильтрует числа по условию: они должны делиться на `-7` и при этом не делиться на `2`.

2. Программа считывает файл обратно (десериализует) и выводит на экран список всех пассажиров и их вещей.
